# Vidha's Fitness App — Core

## Project Type
Static PWA (HTML + CSS + JS, no build step). Deployable as-is via GitHub Pages.

## Files
- `index.html` — app shell, all pages as divs
- `style.css` — all styles, CSS custom properties, dark + light themes
- `data.js` — all workout data (DAYS, FOODS, MEALS, PROTEIN_FOODS, TIPS, SUPPS)
- `app.js` — all logic (rendering, state, timers, storage)
- `manifest.json` — PWA manifest
- `sw.js` — service worker for offline
- `images/` — exercise illustration images (jpg/png)
- `icons/` — PWA icons
